# textrieve v1.2.1 — release notes

## What's new

- **Published on PyPI** — `pip install textrieve` now works (trusted-publisher / OIDC workflow, no tokens).
- **PDF support landing** (from v1.2.0): multi-page PDFs → text with `[Page N]` markers, up to 25 pages / 12 MB.
- **Language hints**: optional `lang` query / `--lang` flag for the OCR engine.
